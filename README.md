# คลังโปรเจกต์ (ต้นแบบเว็บ)

เว็บไซต์ต้นแบบสำหรับค้นหาและแบ่งปันโครงงานรุ่นพี่ รองรับตัวอย่างโครงงานเว็บไซต์, IoT และข้อมูล/AI พร้อมหน้ารายละเอียด พรีวิว และฟอร์มแนบภาพกับไฟล์ PDF/Word

## เปิดดูในเครื่อง

Three.js โหลดจาก jsDelivr CDN จึงต้องเปิดผ่าน local web server และเชื่อมต่ออินเทอร์เน็ต

1. เปิด Terminal ในโฟลเดอร์นี้
2. รัน `python -m http.server 8000`
3. เปิด `http://localhost:8000`

หรือเปิดโฟลเดอร์นี้ด้วย VS Code แล้วใช้ส่วนขยาย Live Server

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub และอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ที่ root
2. เปิด **Settings → Pages** ของ repository
3. ใน **Build and deployment** เลือก **Deploy from a branch** แล้วเลือก branch `main` และ folder `/ (root)`
4. รอให้ Pages เผยแพร่ แล้วเปิด URL ที่ GitHub แสดงในหน้า Pages

เว็บไซต์นี้เป็น static site ไม่ต้องตั้ง build command; Three.js โหลดจาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ต

## ขอบเขตของต้นแบบ

- ค้นหา กรอง เรียงลำดับ เปิดรายละเอียด และบันทึกโครงงานไว้ดูภายหลังได้
- ฟอร์มเพิ่มโครงงานรับภาพและไฟล์ PDF/Word; รายการใหม่บันทึกใน `localStorage` ของเบราว์เซอร์เครื่องนี้
- ไฟล์ที่เลือกอยู่ในหน่วยความจำของแท็บปัจจุบัน การเก็บไฟล์ถาวรและการเปิดใช้ร่วมกันหลายคนต้องต่อ backend, ฐานข้อมูล และ object storage
- ตัวอย่างพรีวิวเว็บไซต์ฝัง URL ที่ใส่ในฟอร์มได้ บางเว็บไซต์ตั้งค่าไม่ให้แสดงใน iframe
- ฉาก Three.js ในส่วนหัวเป็นภาพประกอบ 3 มิติแบบเคลื่อนไหวและปรับตามขนาดหน้าจอ
